# FIRE 계산기

투자 가능 자산을 기준으로 경제적 자립까지의 거리와 기대수명까지 은퇴 후 월 지출을 감당하기 위한 최소 근로 기간을 계산하는 웹앱입니다.

흔히 경제적 자유라고 부르는 상태를 이 계산기에서는 조금 더 현실적인 의미의 경제적 자립으로 다룹니다. FIRE는 Financial Independence, Retire Early의 약자이지만, 이 앱은 특히 Financial Independence에 초점을 둡니다. 총자산 전체가 아니라 실제로 굴릴 수 있는 투자 가능 자산을 기준으로 계산하며, 입력값은 월 단위 현금흐름과 투자 수익률 중심으로 단순화했습니다.

## 주요 기능

- 대한민국 평균 가구 기준 프리셋
- 입력 예시용 FIRE 가구 프리셋
- 은퇴 후 월 지출을 반영한 목표 인출률 기반 경제적 자립 목표 계산
- 국민연금 수령액을 감안한 기대수명까지 자산 소진 최소 근로 기간 계산
- 보수적, 기본, 낙관적 3가지 수익률 시나리오 비교
- 월별 자산 추이 표/그래프 표시
- 월 저축액, 은퇴 후 월 지출, 일회성 지출, 수익률 조건을 동시에 조정하는 가정 비교
- 경제적 자립 개념과 계산 결과 해석을 정리한 `계산기에 대해서` 탭
- 4% 룰, 경제적 자립, 은퇴자금 계산 방법을 설명하는 정적 SEO 가이드 페이지

## 입력값

- 현재 보유 자산
- 현재 월 수입
- 월 평균 소비액
- 은퇴 후 월 지출
- 연평균 투자 수익률
- 연평균 물가 상승률
- 연평균 수입 증가율
- 목표 인출률: 목표 인출률 모드에서 사용
- 출생연도, 기대수명: 기대수명 소진 모드에서 사용
- 국민연금 예상 월 수령액: 기대수명 소진 모드에서 현재 기준 금액으로 입력

대한민국 평균 가구 프리셋의 국민연금 예상 월 수령액은 국민연금연구원 `국민연금 중기재정전망(2025~2029)`의 2026년 노령연금 월평균급여액 전망을 가입기간별 수급자 수로 가중 평균한 뒤 천 원 단위로 반영했습니다.

## 계산기에 대해서

앱의 `계산기에 대해서` 탭은 계산 화면에 넣기에는 긴 개념 설명과 주의사항을 따로 정리합니다.

- 경제적 자립은 노동소득에 전적으로 의존하지 않아도 생활을 유지할 수 있는 상태입니다. 반드시 일을 그만둔다는 뜻은 아니며, 원치 않는 일을 생계 때문에 계속해야 하는 압박이 줄어드는 상태에 가깝습니다.
- FIRE는 Financial Independence, Retire Early의 약자입니다. 이 계산기에서는 Retire Early보다 Financial Independence, 즉 경제적 자립에 더 초점을 둡니다.
- 미래의 명목 금액과 오늘 돈 기준의 현재 가치는 구매력이 다르므로 계산 결과를 볼 때 구분해서 이해해야 합니다.
- 4% 룰은 모든 사람에게 보장되는 법칙이 아니라 과거 시장 데이터를 바탕으로 한 경험칙에 가깝습니다.
- 평균 수익률이 같더라도 수익률이 발생하는 순서, 소비 수준, 인출 가능한 금융자산 여부에 따라 결과는 크게 달라질 수 있습니다.
- 이 계산기는 미래 예측 도구가 아니라 입력한 가정에 따른 시뮬레이션 도구입니다.

## 도움말과 계산 기준

앱 오른쪽 상단의 `계산 기준` 버튼에서 아래 내용을 확인할 수 있습니다.

### 1. 주요 계산식

```text
월 저축액 = 월 수입 - 현재 월 소비액
```

은퇴 전 월별 자산은 월 수익률과 월 저축액을 반영해 계산합니다.

```text
다음 달 자산 = 현재 자산 * (1 + 월 수익률) + 월 저축액
```

은퇴 후에는 월 저축액 대신 은퇴 후 월 지출과 국민연금 수령액을 반영합니다.

```text
은퇴 후 자산 = 현재 자산 * (1 + 월 수익률) - 은퇴 후 월 지출 + 국민연금
```

목표 인출률 방식의 필요 자산은 은퇴 후 연간 지출을 목표 인출률로 나눕니다.

```text
필요 자산 = 은퇴 후 월 지출 * 12 / 목표 인출률
```

예를 들어 은퇴 후 월 지출이 400만 원이고 목표 인출률이 3.5%라면 `4,800만 원 / 0.035 = 약 13.7억 원`입니다.

은퇴 후 월 지출이 늘 때 추가로 필요한 자산은 다음처럼 계산합니다.

```text
추가 필요 자산 = 추가 은퇴 후 월 지출 * 12 / 목표 인출률
```

예를 들어 은퇴 후 월 지출이 50만 원 늘고 목표 인출률이 3.5%라면 `600만 원 / 0.035 = 약 1.7억 원`입니다.

### 2. 명목 기준과 현재 가치

명목 기준은 미래 시점에 실제로 필요한 금액입니다. 현재 가치는 미래 금액을 오늘 돈의 가치로 환산한 금액입니다.

- 명목 기준: 미래에 실제 필요한 금액
- 현재 가치: 오늘 돈 기준으로 환산한 금액

예를 들어 20년 후 20억 원이 필요하더라도, 물가상승률을 반영하면 오늘 돈 가치로는 더 낮게 보일 수 있습니다.

### 3. 목표 인출률 방식

목표 인출률 방식은 은퇴 후 매년 자산의 일정 비율을 꺼내 쓴다고 가정해 은퇴 후 월 지출을 감당하는 데 필요한 자산을 계산합니다.

```text
필요 자산 = 은퇴 후 월 지출 * 12 / 목표 인출률
```

인출률이 낮을수록 더 보수적인 계산입니다.

- 4.0%: 연간 지출의 25배 필요
- 3.5%: 연간 지출의 약 28.6배 필요
- 3.0%: 연간 지출의 약 33.3배 필요

이 방식은 단순하고 직관적이지만, 국민연금이나 은퇴 후 현금흐름을 세밀하게 반영하기는 어렵습니다.

### 4. 기대수명 소진 방식

기대수명 소진 방식은 은퇴 후 자산을 영원히 유지한다고 보지 않고, 기대수명까지 자산이 유지되는지를 계산합니다.

- 은퇴 전: 자산 증가 + 저축
- 은퇴 후: 자산 증가 - 은퇴 후 월 지출 + 국민연금

목표 인출률 방식보다 현실적인 시뮬레이션에 가깝지만, 기대수명보다 오래 살거나 수익률이 낮아지면 결과가 달라질 수 있습니다.

### 5. 국민연금 입력 기준

국민연금 월 예상액은 현재 가치 기준으로 입력합니다. 예를 들어 65세 이후 받을 국민연금이 오늘 돈 가치로 월 100만 원 정도라고 예상된다면, 100만 원을 입력하면 됩니다.

- 입력값: 오늘 돈 가치 기준 국민연금
- 계산값: 미래 시점의 명목 국민연금

미래 수령 시점의 명목 금액은 물가상승률을 반영해 자동으로 계산됩니다. 미래에 받을 명목 금액을 그대로 입력하면 결과가 과대평가될 수 있습니다.

### 6. 가정 비교

가정 비교는 현재 입력값을 저장하지 않고, 여러 조건을 동시에 조정했을 때 결과가 얼마나 달라지는지 비교하는 기능입니다.

- 월 저축액을 50만 원 단위로 조정하면 결과가 얼마나 달라질까?
- 은퇴 후 월 지출을 50만 원 단위로 조정하면 결과가 얼마나 달라질까?
- 일회성 지출을 선택한 단위로 반영하면 결과가 얼마나 달라질까?
- 연평균 투자 수익률을 1%p 단위로 조정하면 결과가 얼마나 달라질까?

비교 가정은 실제 입력값에 저장되지 않고, 비교 계산에만 사용됩니다.

### 7. 계산기의 한계

이 계산기는 입력한 가정을 바탕으로 한 추정 도구입니다.

실제 결과는 투자수익률, 물가상승률, 세금, 건강보험료, 주거비, 자녀 교육비, 국민연금 제도 변화, 예상보다 긴 수명 등에 따라 달라질 수 있습니다. 특히 수익률은 매년 일정하지 않고, 은퇴 직후 큰 하락장이 오면 자산 소진 속도가 빨라질 수 있습니다.

따라서 계산 결과는 확정적인 은퇴일이 아니라, 소비, 저축, 투자 가정이 장기적으로 어떤 차이를 만드는지 확인하는 참고값으로 봐야 합니다.

## 계산 모드

### 목표 인출률

은퇴 후 월 지출 기준 경제적 자립 목표 자산을 계산합니다.

```text
경제적 자립 목표 자산 = 은퇴 후 월 지출 * 12 / 목표 인출률
```

매월 다음 흐름으로 최대 100년까지 시뮬레이션합니다.

1. 연평균 투자 수익률을 월 수익률로 환산합니다.
2. 현재 자산에 월 수익률을 적용합니다.
3. 월 수입에서 현재 월 소비액을 뺀 저축액을 더합니다.
4. 투자 가능 자산이 경제적 자립 목표 자산 이상이 되는 첫 달을 찾습니다.

보수적, 기본, 낙관적 시나리오는 입력한 수익률에 각각 `-2%p`, `0`, `+2%p`를 적용합니다.

보통 4% 인출률은 트리니티 연구에서 알려진 30년 은퇴 기간 기준 참고값입니다. 은퇴 기간이 길어질수록 3~3.5%처럼 더 보수적인 인출률을 쓰는 경우가 많습니다.

### 기대수명 소진

은퇴 후 월 지출을 감당하면서 기대수명까지 자산이 한 번도 0 미만으로 내려가지 않는 가장 빠른 은퇴 시점을 찾습니다.

매월 다음 흐름으로 시뮬레이션합니다.

```text
근로 중 자산 = 지난 달 자산 * (1 + 월 수익률) + 월 수입 + 국민연금 - 현재 월 소비액
은퇴 후 자산 = 지난 달 자산 * (1 + 월 수익률) + 국민연금 - 은퇴 후 월 지출
```

출생연도만 입력받기 때문에 현재 나이는 `현재연도 - 출생연도`로 계산합니다.

국민연금 수령 시작 나이는 출생연도별 노령연금 지급개시연령 기준을 적용합니다.

| 출생연도 | 국민연금 수령 시작 나이 |
| --- | --- |
| 1952년 이전 | 60세 |
| 1953년 ~ 1956년 | 61세 |
| 1957년 ~ 1960년 | 62세 |
| 1961년 ~ 1964년 | 63세 |
| 1965년 ~ 1968년 | 64세 |
| 1969년 이후 | 65세 |

국민연금 예상 월 수령액은 현재 기준 금액으로 입력하고, 계산에서는 물가상승률을 반영한 명목 금액으로 환산합니다. 수령 시작 나이 이후에는 근로 중이어도 월 현금흐름에 포함합니다.

은퇴 시점을 1개월씩 뒤로 미루며, 전체 기간의 자산이 항상 0 이상으로 유지되는 최초의 근로 개월 수를 반환합니다. 이미 현재 자산만으로 기대수명까지 자산을 유지할 수 있으면 `0개월`로 표시합니다.

계산 결과에는 최적 은퇴 시점 기준 월별 자산 추이 그래프와 표를 함께 표시합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

기본 개발 서버는 Vite 설정을 따릅니다.

## 테스트와 빌드

```bash
npm test
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. `npm run build`는 Vite 빌드 뒤에 SEO 가이드용 정적 HTML과 sitemap을 함께 생성합니다.

생성되는 가이드 URL은 아래와 같습니다.

- `/guides/4-percent-rule/`
- `/guides/financial-independence/`
- `/guides/retirement-fund/`

가이드 본문과 메타데이터는 `src/seoPages.json`에서 관리합니다. Vercel에서는 Vite 프로젝트로 자동 감지되며, 별도 설정 없이 다음 값으로 배포할 수 있습니다.

- Build Command: `npm run build`
- Output Directory: `dist`

## 주의사항

이 계산기는 장기 재무 계획을 단순화한 시뮬레이션 도구입니다. 세금, 부채 상환, 국민연금 감액/연기/조기수령, 자산 배분, 투자 변동성, 건강보험료, 주거비 변화, 자녀 교육비 같은 항목은 별도로 모델링하지 않습니다. 실제 은퇴 계획에는 더 보수적인 가정과 별도 검토가 필요합니다.
