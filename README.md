# FIRE 계산기

투자 가능 자산을 기준으로 경제적 자유(FIRE) 도달 시점과 기대수명까지 현재 소비 수준을 유지하기 위한 최소 근로 기간을 계산하는 웹앱입니다.

총자산 전체가 아니라 실제로 굴릴 수 있는 투자 가능 자산을 기준으로 계산합니다. 입력값은 월 단위 현금흐름과 실질 수익률 중심으로 단순화했습니다.

## 주요 기능

- 대한민국 평균 가구 기준 프리셋
- 입력 예시용 FIRE 가구 프리셋
- 목표 인출률 기반 FIRE 목표 계산
- 기대수명까지 자산을 소진하는 최소 근로 기간 계산
- 보수적, 기본, 낙관적 3가지 수익률 시나리오 비교
- 월별 자산 추이 표/그래프 표시

## 입력값

- 현재 보유 자산
- 월 평균 저축액
- 월 평균 소비액
- 연평균 예상 실질 수익률
- 목표 인출률: 목표 인출률 모드에서 사용
- 현재 나이, 기대 수명: 기대수명 소진 모드에서 사용

## 계산 모드

### 목표 인출률

현재 소비 수준 기준 FIRE 목표 자산을 계산합니다.

```text
FIRE 목표 자산 = 월 평균 소비액 * 12 / 목표 인출률
```

매월 다음 흐름으로 최대 100년까지 시뮬레이션합니다.

1. 연평균 실질 수익률을 월 수익률로 환산합니다.
2. 현재 자산에 월 수익률을 적용합니다.
3. 월 평균 저축액을 더합니다.
4. 투자 가능 자산이 FIRE 목표 자산 이상이 되는 첫 달을 찾습니다.

보수적, 기본, 낙관적 시나리오는 입력한 실질 수익률에 각각 `-2%p`, `0`, `+2%p`를 적용합니다.

보통 4% 인출률은 트리니티 연구에서 알려진 30년 은퇴 기간 기준 참고값입니다. 조기 은퇴처럼 은퇴 기간이 길어질수록 3~3.5%처럼 더 보수적인 인출률을 쓰는 경우가 많습니다.

### 기대수명 소진

현재 소비 수준을 유지하면서 기대수명 시점에 자산이 0 이상이 되는 가장 빠른 은퇴 시점을 찾습니다.

매월 다음 흐름으로 시뮬레이션합니다.

```text
근로 중 자산 = 지난 달 자산 * (1 + 월 실질 수익률) + 월 평균 저축액
은퇴 후 자산 = 지난 달 자산 * (1 + 월 실질 수익률) - 월 평균 소비액
```

은퇴 시점을 1개월씩 뒤로 미루며, 기대수명 시점의 최종 자산이 0 이상이 되는 최초의 근로 개월 수를 반환합니다. 이미 현재 자산만으로 기대수명까지 버틸 수 있으면 `0개월`로 표시합니다.

계산 결과에는 최적 은퇴 시점 기준 월별 자산 추이 그래프와 표를 함께 표시합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

기본 개발 서버는 Vite 설정을 따릅니다.

## 테스트와 빌드

```bash
npm test
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. Vercel에서는 Vite 프로젝트로 자동 감지되며, 별도 설정 없이 다음 값으로 배포할 수 있습니다.

- Build Command: `npm run build`
- Output Directory: `dist`

## 주의사항

이 계산기는 장기 재무 계획을 단순화한 시뮬레이션 도구입니다. 세금, 부채 상환, 연금, 자산 배분, 투자 변동성, 건강보험료, 주거비 변화, 자녀 교육비 같은 항목은 별도로 모델링하지 않습니다. 실제 은퇴 계획에는 더 보수적인 가정과 별도 검토가 필요합니다.
