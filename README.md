# FIRE 계산기

투자 가능 자산을 기준으로 경제적 자유(FIRE) 도달 시점을 계산하는 웹앱입니다.

총자산 전체를 FIRE 자산으로 보지 않고, 실제로 은퇴 후 인출 가능한 투자 가능 자산을 중심으로 계산합니다. 거주용 부동산과 기타 실물자산은 참고값으로 입력할 수 있지만, 기본 FIRE 판정에는 포함하지 않습니다.

## 주요 기능

- 대한민국 평균 가구 기준 프리셋
- 입력 예시용 FIRE 가구 프리셋
- 현재 투자 가능 자산 기준 FIRE 목표 계산
- 부채 상환액과 상환 종료 시점 반영
- 은퇴 후 예상 수입, 국민연금/퇴직연금 반영
- 보수적, 기본, 낙관적 3가지 시나리오 비교
- 연도별 투자 가능 자산과 FIRE 목표 자산 표/그래프 표시

## 계산 기준

매년 다음 흐름으로 최대 100년까지 시뮬레이션합니다.

1. 투자 가능 자산은 연 투자 수익률만큼 증가합니다.
2. 연 수입은 연 수입 증가율만큼 증가합니다.
3. 연 생활비는 인플레이션율만큼 증가합니다.
4. 저축액은 `연 수입 - 연 생활비 - 연 부채 상환액`으로 계산합니다.
5. 투자 가능 자산이 해당 연도의 FIRE 목표 자산 이상이 되는 첫 해를 찾습니다.

FIRE 목표 자산은 다음 식을 사용합니다.

```text
max(연 생활비 - 은퇴 후 예상 연 수입, 0) / 목표 인출률
```

100년 안에 목표 자산에 도달하지 못하면 `도달 어려움`으로 표시합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

기본 개발 서버는 Vite 설정을 따릅니다.

## 테스트와 빌드

```bash
npm test
npm run build
```

빌드 결과는 `dist/`에 생성됩니다. Vercel에서는 Vite 프로젝트로 자동 감지되며, 별도 설정 없이 다음 값으로 배포할 수 있습니다.

- Build Command: `npm run build`
- Output Directory: `dist`

## 주의사항

이 계산기는 장기 재무 계획을 단순화한 시뮬레이션 도구입니다. 세금, 자산 배분, 투자 변동성, 건강보험료, 주거비 변화, 자녀 교육비 같은 항목은 별도로 모델링하지 않습니다. 실제 은퇴 계획에는 더 보수적인 가정과 별도 검토가 필요합니다.
